# 好学 — PROJECT CONTEXT

## Hackathon

赛题：Echo｜未来·回响 — 教育

命题核心：

> 教育，是唯一一个“每个人都被塑造过、每个人都可以重塑它”的领域。
> 你希望教育如何对待下一个像你一样的人？

好学的回答：

> 教育不应该只告诉学生“你错了什么”，而应该真正理解“你为什么会错”，并根据长期学习痕迹决定“你下一步最需要学什么”。

## Product Statement

> 一个记得你如何学习，并据此决定下一步如何教你的 Personal Learning Agent。

## Design Statement

AI 不应该成为 UI 主角。

真正的主角是：

> **我的学习状态。**
